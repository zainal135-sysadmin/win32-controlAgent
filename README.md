# win32-controlAgent

A Windows automation agent built with Python, designed to control and manage 
Windows processes through an intelligent command-based system.

## Features
- Process management & monitoring
- Window control automation
- Command-based control system
- Middleware authentication & permission system

## Tech Stack
- Python
- Win32 API
